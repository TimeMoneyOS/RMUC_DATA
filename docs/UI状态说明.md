# 转播式状态层

## 已实现

- 零血量：卡片、地图轮廓及轨迹灰色；地图增加叉号。文案为“零血量”，避免把未上场/判罚混作确定战亡。
- 复活转变：相邻有效样本从血量 0 恢复为正值后，绿色虚线环及卡片提示 3 秒。3 秒是 UI 提示时长，不是规则无敌时长。
- 雷达易伤：按“是否易伤”逐秒更新，橙色卡片及地图环。
- 无人机：四旋翼 SVG 和菱形外框；哨兵：盾形 SVG 和六边轮廓。图标由本项目自绘，未取得官方转播原始图标。
- UAV 反制：按事件阵营关联无人机，即使 robot_id 为 NULL 也可呈现。扫屏、字幕、状态卡提示均以回放时间为基准，跳转和暂停可重建。
- 场地面板：能量机关、飞镖闸门、科技核心装配、跨越增益的最近事件及时间；悬浮查看类别、数值及备注。
- 下方事件流：最近 12 秒内的四条关键事件。关闭“事件”同时关闭扫屏及事件流。

## 数据限制

SQLite timeseries 没有裁判主状态、复活无敌起止时间和持续道具占领位。绿色只是血量恢复提示，不能据此证明无敌。场地面板展示最后一次事件，不把一次触发显示成长期有效；高地/堡垒占领显示未知。

当前官方区域赛参考视频：https://www.bilibili.com/video/BV15n5164E2Z/ 。浏览器能打开官方账号页面，但播放器报告“无法播放媒体”，因此没有完成视频逐帧对照；上述 UI 是参考用户描述制作的转播式呈现，不宣称精确复制官方 HUD。

## 验证

`node tests/test_presentation.js` 验证零血量、恢复转变、首次出现不误判、反制阵营与 NULL 编号、提示到期和回退时间。

浏览器实测东部第5场第1局：32.5 秒蓝方 UAV 反制扫屏，101.5 秒红方英雄/步兵3零血量灰显，121.5 秒英雄绿色恢复提示。测试时回放暂停，提示保持固定而不按现实时间消失。
