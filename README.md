# RMUC 2026 二维转播式回放

当前阶段：第一版二维回放已可运行。

## 启动

双击 `start_replay.bat`，或在本目录执行 `python backend/server.py`，访问 http://127.0.0.1:8765 。仅需 Python 3，无需安装第三方库或联网。停止服务时在启动终端按 Ctrl+C。

当前支持：613 局比赛检索、双方状态栏、地图位置插值、播放/暂停、逐秒、倍速、时间轴跳转、轨迹、发弹/受击提示、关键事件跳转、机器人详情、缩放拖动和选中跟随。

第一版前端使用原生 JavaScript，减少构建和依赖成本；后续复杂化时再迁移 TypeScript。单局缓存为服务端内存缓存，最多 3 局。

## 已验证及限制

- Python 编译与 JavaScript 语法检查通过；16 个实体、样本位置及事件数量对照数据库通过。
- 浏览器实际加载与逐秒状态更新已检查，1366×768 画面已检查。
- 当前底图为全国赛规则提取图，暂用于视觉配准；区域赛版本和精确坐标变换尚未完成核对。朝向按度绘制，但零方向仍需独立验证。
- 建筑显示于双方状态栏，未将零坐标绘成地图位置。异常出界位置不绘制，不修改原始数据；无人机出动状态未推断。
- 未实现自动导播、视频导出、机器人标签避让；未完成完整单局播放和长期帧率测量。
